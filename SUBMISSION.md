# Submission notes — Learning HTML

## Title

Learning HTML

## Short description (16 words)

A four-page learning site with a quote collection, five project ideas and two small JavaScript toys.

## Long description

Learning HTML is the website I built alongside the Web Technologies 2026 course. It is a small, four-page site that practises the whole foundation: semantic HTML, one external stylesheet and a little JavaScript, without a framework or a server.

The pages are a homepage with a hero image and an overview; a collection of sixteen quotations about the web, design and code; a planning page with five project ideas, each with a reader, four pages and a smallest version; and a machine page with two toys. The quotes page picks a random quotation for its hero, and the machine page has a useless machine and a twenty-second game.

It is written for students who are learning the same material: the text explains what each part does and why it is there, rather than hiding it. The navigation is written once in `nav.html` and injected by `nav.js`, so it is a working example of DRY, not just a slogan.

The design uses warm paper, dark ink and two accents, with a serif for headings and a monospace for labels. It is responsive, keyboard accessible and tested at 375 px and 1920 px. The images are local; the hero photograph is CC0 and credited in `CREDITS.md`.

Everything is plain HTML, CSS and JavaScript. There is no build step, no framework, no server and no database.
