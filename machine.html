Two toys

One switch. One game.

A useless machine has one job: to turn itself off. A small game has one job too: to be played for twenty seconds and then stop. Both are built with plain JavaScript.

Toy 01

The useless machine

Press the switch. The machine will turn it off again. That is the whole idea.

The machine is off. Please leave it off.

Toy 02

Catch the bug

Twenty seconds. Tap the bug. It moves every time you catch it — and every time you miss.

Score 0

Time 20s

Press start. The bug appears in one cell.

Under the hood

What the JavaScript does

Neither toy needs a library. The machine listens for one click, adds a class and uses a timeout to put the switch back. The game creates nine buttons, picks a random index and runs a one-second interval.

Accessibility

The switch is a real button with aria-pressed. The game cells are buttons, and the score and status are announced with aria-live. Both work from the keyboard.
