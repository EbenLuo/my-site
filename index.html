How it is built

Structure, style, behaviour

The site follows the course: semantic HTML first, one external stylesheet, then JavaScript only where it earns its place.

  • Semantic landmarks, one h1 per page, and a skip link.
  • Navigation written once in nav.html, injected by nav.js.
  • Responsive grid and fluid type; it works on a phone.
  • No framework, no build step, no server, no database.

The brief

Four pages, working navigation, one interaction, live online. The site is in English, like the course.
